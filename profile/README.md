# 오픈소스 기반 IoT-Platform
NHN Academy IoT Service Platform Project

오픈소스를 활용한 IoT 데이터 관리 및 시각화 서비스로, ChirpStack, Mosquitto, Node-RED, Telegraf, InfluxDB, Grafana 등을 통합하여 누구든 mqtt를 지원하는 센서 소유시 센서 데이터 수집, 처리 및 시각화 기능을 제공하는 플랫폼입니다.
